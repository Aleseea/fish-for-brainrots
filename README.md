# Fish for Brainrots Calculators

Trade calculator, value calculator and collection tracker for
[Fish for Brainrots](https://fortnite-creator-islands.fandom.com/wiki/Fish_for_Brainrots),
a Fortnite island by Pandvil. It is the same set of calculators as the
[Fortnite Creator Islands Wiki](https://fortnite-creator-islands.fandom.com/wiki/Fish_for_Brainrots),
on a page that also works on phones (Fandom's mobile site doesn't run wiki
scripts).

Live: https://aleseea.github.io/fish-for-brainrots/

## How it works

- `app.js` fetches the calculators' data from the wiki's public API each time
  the page loads, so new or changed values on the wiki show up here straight
  away.
- `calc.js` and `calc.css` are copies of the wiki's own calculator script and
  styles (generated by `build.py` from the wiki sources), so the maths and
  wording match the wiki exactly.
- My collection is kept in your browser on your device only. Nothing is sent
  anywhere except the read-only request to the wiki.

Unofficial fan tool.
